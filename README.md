# RetroTunes — descargas

Instaladores públicos de **RetroTunes**, el sincronizador y reproductor de iPod con
interfaz estilo Norton Commander. El código fuente es privado; aquí solo se publican
las versiones listas para instalar.

## Descargar

Ve a **[Releases](../../releases/latest)** y descarga:

- **RetroTunes-Setup-Offline.exe** — instalador completo (incluye Python, iOpenPod,
  ffmpeg y Chromaprint; no necesita internet salvo para carátulas). Recomendado.
- **RetroTunes-Setup.exe** — instalador online ligero (descarga las dependencias
  durante la instalación).

Los `.exe` no están firmados, así que SmartScreen mostrará un aviso: pulsa
"Más información" → "Ejecutar de todas formas".

RetroTunes se **actualiza solo**: cuando hay una versión nueva, la aplica al arrancar.
